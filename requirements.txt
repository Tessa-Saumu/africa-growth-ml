# Runtime dependencies for the Streamlit app.
#
# Lower bounds are pinned to the versions the model was pickled with
# (see models/model_metadata.json -> library_versions). scikit-learn does not
# guarantee unpickling across minor versions: loading the committed
# growth_model.joblib under an older scikit-learn raises or silently
# mis-predicts, so ">=1.3" was a real deployment hazard rather than
# permissiveness.
#
# numpy is held below 2.0 because the model was built against 1.26.x. Note
# that numpy 1.26.x ships wheels for cp39-cp312 only, so this app must be
# deployed on Python 3.11 or 3.12 — on Streamlit Community Cloud, set the
# Python version under "Advanced settings" when creating the app (Cloud
# defaults to 3.12 and ignores runtime.txt / .python-version).
pandas>=2.3.3,<3.0
numpy>=1.26.4,<2.0
scikit-learn>=1.9.0,<2.0
matplotlib>=3.7,<4.0
seaborn>=0.12,<1.0
# streamlit >= 1.62: .streamlit/config.toml uses [[theme.fontFaces]] plus the
# baseRadius / borderColor / dataframeHeaderBackgroundColor theme options that
# carry the Terracotta Editorial design tokens into Streamlit's own chrome.
streamlit>=1.62,<2.0
joblib>=1.3,<2.0
pyarrow>=14.0
pyyaml>=6.0,<7.0
